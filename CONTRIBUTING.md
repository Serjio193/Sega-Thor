# Contributing

Keep reverse-engineered notes, clean-room C++ code, tests, and tooling in this
repository. Do not commit commercial ROM images or extracted copyrighted
assets.

Prefer small changes with tests. When translating a routine from 68000 code,
document the original address and any verified RAM/VDP side effects.

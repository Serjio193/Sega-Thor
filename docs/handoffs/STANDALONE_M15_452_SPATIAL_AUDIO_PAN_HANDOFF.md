## 1. Architectural Summary & System Context

This milestone reverse-engineers the positional spatial audio dispatch engine in Beyond Oasis.
All sound effects generated by entities in the game world pass through this subsystem to determine:
1. Whether the sound is non-spatial (sound ID `< 0x200` — global music / menu / HUD effects jump directly to the driver at `$60004`).
2. Distance attenuation relative to Player Ali (`$FF19F0`, `$FF19F4`), taking isometric 1.25x vertical scaling into account.
3. Stereo L/R panning based on horizontal displacement from Ali.
4. Distance culling (inaudible sounds are silenced/culled before reaching the sound driver).

### Subroutines in this Range:
1. `0x00E78E..0x00E7A6` (`spatial_sound_coords_flag_set` — 12 callers):
   - Sound at arbitrary coordinates `(d1, d2)` with flag bit 31 set.
2. `0x00E7A6..0x00E7E8` (`spatial_sound_coords_flag_clear` — 25 callers):
   - Sound at arbitrary coordinates `(d1, d2)` with flag bit 31 clear.
3. `0x00E7E8..0x00E7FC` (`spatial_sound_entity_flag_set` — 34 callers):
   - Sound at caller entity position `+$8(a6), +$C(a6)` with bit 31 set.
4. `0x00E7FC..0x00E834` (`spatial_sound_entity_flag_clear` — 78 callers):
   - Sound at caller entity position `+$8(a6), +$C(a6)` with bit 31 clear.
5. `0x00E834..0x00E90E` (`spatial_audio_distance_attenuation_and_pan`):
   - Isometric distance:
     - `dy_iso = |dy| + (|dy| >> 2)` (1.25x isometric scaling).
     - `dist = max(|dx|, dy_iso)`.
   - **Mode A (Sound ID >= 0x300):**
     - Near deadzone: if `dist <= 0x58` (88px), `dist = 0`.
     - Step attenuation: `dist >>= 5` (32px buckets).
     - Culling: if `step > 7` (> 312px away), sound is culled!
     - Stereo pan: if `|dx| >= 0x40` (64px), adds `0x42` (left) or `0x82` (right).
   - **Mode B (0x200 <= Sound ID < 0x300):**
     - Culling: if `dist >= 0x110` (272px), sound is culled!
     - Stepped volume reduction: `+1` if `>= 0xB0` (176px), `+1` if `>= 0xE0` (224px).
     - Stereo pan: if `|dx| >= 0x60` (96px), sets bit 6 (`0x40`, left) or bit 7 (`0x80`, right).
   - Sound driver execution: `jmp $60004.l`.

## 2. C++20 Cleanroom API Specification

```cpp
namespace oasis::audio {

enum class StereoPan : uint8_t {
    Center = 0,
    Left = 1,
    Right = 2
};

struct SpatialSoundParams {
    bool audible{false};
    uint8_t volume_attenuation{0};
    StereoPan pan{StereoPan::Center};
    uint32_t driver_command{0};
};

constexpr SpatialSoundParams calculate_spatial_audio(
    uint32_t sound_id, int16_t sound_x, int16_t sound_y,
    int16_t player_x, int16_t player_y) noexcept
{
    // Non-spatial sounds bypass spatial attenuation
    if ((sound_id & 0xFFFFU) < 0x200U) {
        return {true, 0, StereoPan::Center, sound_id};
    }

    int16_t raw_dx = sound_x - player_x;
    int16_t dx = (raw_dx < 0) ? -raw_dx : raw_dx;
    int16_t raw_dy = sound_y - player_y;
    int16_t dy = (raw_dy < 0) ? -raw_dy : raw_dy;
    int16_t dy_iso = dy + (dy >> 2); // 1.25x isometric scaling
    int16_t dist = (dx > dy_iso) ? dx : dy_iso;

    uint16_t base_id = static_cast<uint16_t>(sound_id & 0xFFFFU);
    if (base_id >= 0x300U) {
        // Mode A
        int16_t atten_dist = (dist > 0x58) ? static_cast<int16_t>(dist - 0x58) : 0;
        uint16_t step = static_cast<uint16_t>(atten_dist >> 5);
        if (step > 7U) {
            return {false, 0, StereoPan::Center, 0}; // Culled
        }

        StereoPan pan = StereoPan::Center;
        if (dx >= 0x40) {
            pan = (raw_dx < 0) ? StereoPan::Left : StereoPan::Right;
        }

        return {true, static_cast<uint8_t>(step), pan, sound_id};
    } else {
        // Mode B (0x200 <= ID < 0x300)
        if (dist >= 0x110) {
            return {false, 0, StereoPan::Center, 0}; // Culled
        }

        uint8_t reduction = 0;
        if (dist >= 0xB0) ++reduction;
        if (dist >= 0xE0) ++reduction;

        StereoPan pan = StereoPan::Center;
        if (dx >= 0x60) {
            pan = (raw_dx < 0) ? StereoPan::Left : StereoPan::Right;
        }

        return {true, reduction, pan, sound_id};
    }
}

} // namespace oasis::audio
```

## 3. Acceptance Criteria

1. **Non-Spatial Sound Bypass:** Direct driver forwarding for sound IDs `< 0x200`.
2. **Isometric 1.25x Distance Scaling:** Precise `dy + (dy >> 2)` calculation.
3. **Mode A & B Culling Limits:** Strict culling at `> 312px` (Mode A) and `>= 272px` (Mode B).
4. **Stereo Panning Parity:** Exact threshold matching (`>= 64px` for Mode A, `>= 96px` for Mode B).
5. All C++ source and test files must strictly stay `<= 500 lines`.

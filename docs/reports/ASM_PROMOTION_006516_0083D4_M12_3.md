## Decoder and reassembler coverage

The existing decoder was minimally extended for legitimate dynamic-bit forms:

- `BSET D1,(A1,D0.W)` at `0x007B24` (`0x03F1`);
- `BSET D0,($00FF0DBA).L` at `0x007BEC` (`0x01F9`).

The exact IR and deterministic synthetic regression cover dynamic
`BTST/BCHG/BCLR/BSET` forms. The reassembler emits `dc.w` only when a
byte-immediate extension contains the canonical `0xFF` high byte that vasm
normalizes if written as a mnemonic (for example the exact `ANDI.B` bytes in
this region). This is still executable ASM source ownership and preserves the
original words; it is not an executable `incbin` or a ROM substitution.
